# S-105 [SAFETY] — ★ Forbidden-pattern test suite

**Epic:** 1 (Foundation) · **Safety story:** Yes · **Status:** Done

## Story
Give every forbidden pattern in `09-test-plan.md §6` a cheap grep/AST test that
**fires on violation**. These are the guardrails that catch the 2 a.m. refactor —
the moment a coding agent reaches for `LogisticRegression(multi_class=...)`
because it is the pattern-matched answer, or defaults a clinical timestamp to
`datetime.now()` on autopilot. Each guard scans the real source tree (must be
clean) **and** is itself proven to bite by feeding it a deliberate violation.

## The eight patterns (`09 §6`)
| # | Pattern | Detector |
|---|---------|----------|
| 1 | `multi_class` keyword anywhere | AST keyword `multi_class` |
| 2 | `for state in range(1, 6): … fit(` (per-state sub-models) | AST for-loop over `range(1,6)` containing a `.fit(` call |
| 3 | `train_test_split(…, shuffle=True)` (random split) | AST keyword `shuffle=True` |
| 4 | `accuracy_score` in a reporting module | AST name/attr/import `accuracy_score` |
| 5 | `assert` in `core/safety.py` | AST `Assert` in `core/safety.py` |
| 6 | Manual IOB assignment (IOB from user input) | AST assign to `*iob*` from a request/form/payload source |
| 7 | **`datetime.now()` populating a clinical timestamp** | AST assign/keyword to a clinical-ts name with a `now()/utcnow()/today()` value |
| 8 | `pre_bg` passed to the state-binner on the input path | AST call to a binner with a `pre_bg` argument |

## The `datetime.now()` vs `logged_at` distinction (ADR-8) [SAFETY]
`logged_at = datetime.now()` is **correct** — `logged_at` *is* the system clock.
`meal.datetime = datetime.now()` is **catastrophic** — it fabricates
`bolus_offset_min` and `elapsed_min` with no error and no way to detect it
afterwards. The detector therefore keys on the **target name**: it fires for
`datetime` / `pre_bg_time` / `post_bg_time` / bolus-time targets and is silent
for `logged_at`. The suite proves **both** halves: the violation snippet fires,
a `logged_at = datetime.now()` snippet does **not**.

## TDD strategy (SDET)
`tests/forbidden/test_forbidden_patterns.py`:
- `test_source_tree_is_free_of_<pattern>` — the detector finds nothing in the
  real source packages (`core/features/models/prescribe/data/api/cli`).
- `test_detector_fires_on_<pattern>` — the detector returns a finding for a
  crafted violation snippet. **This is the "assert each test fires" AC.**
- `test_logged_at_now_is_not_flagged` — the ADR-8 negative control.

**RED evidence:** a temporary module carrying every forbidden pattern is planted
in a scanned package; the `test_source_tree_is_free_of_*` tests go RED (each
guard bites); the module is then removed and they return GREEN. Recorded in the
commit. (`10-backlog` S-105 TDD: *"Deliberately introduce each pattern; assert
each test fires."*)

**Adversarial angle:** *"These will look like dead weight."* They are the guards
that catch the silent-corruption refactor. **Do not delete them.** Each is
paired with a fires-on-violation test so deleting the guard logic also reddens
its own proof.
