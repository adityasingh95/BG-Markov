# S-201 — Schema + migrations

**Epic:** 2 (Data Layer) · **Safety story:** No (but carries ADR-8 and REQ-054
structural guarantees) · **Status:** In progress

## Story
Stand up the persistent schema — all tables in `04-data-model.md` — as
SQLAlchemy 2.0 ORM models plus an Alembic initial migration, on SQLite (WAL).
Her data must survive schema changes (that is why Alembic exists here) and must
never be silently corrupted at the structural level: signed offsets stay signed,
`net_carbs_g` cannot go negative, reported time and log time are separate
columns, and clinical constants are versioned rather than overwritten.

This story ships **structure**, not behaviour: no validity engine (S-203), no
timestamp-capture flow (S-202), no repositories beyond what versioning needs.

## Requirement sources
- **REQ-002** — pre-BG, macros, meal bolus, correction bolus captured per meal.
- **REQ-005** — `logged_at` (system clock) stored separately from `datetime`
  (reported).
- **REQ-006** — every bolus written to `bolus_log`.
- **REQ-007** — daily Tresiba dose + time logged (`basal_log`).
- **REQ-054** — clinical constants are versioned, never overwritten
  (`patient_profile`).

## Tables (per `04-data-model.md`)
`patient_profile`, `bolus_log`, `basal_log`, `meal_event`, `correction_event`,
`dish`, `prediction_log`, `model_artifact`, `audit_log`.

## Acceptance criteria (backlog)
- [ ] All tables present per `04-data-model.md`.
- [ ] `bolus_offset_min` accepts **negatives** (signed; no positive-only
      constraint).
- [ ] `net_carbs_g` **computed and floored at 0** — `max(carbs_g − fiber_g, 0)`.
- [ ] `logged_at` present and **distinct** from `datetime`.
- [ ] `patient_profile` **versioned, never updated in place**.

## Design decisions
- **`net_carbs_g` is a DB-generated column** — `Computed("max(carbs_g -
  fiber_g, 0)", persisted=True)`. Flooring lives in the schema, not in Python,
  so no write path can produce a negative net-carb value (contrast the
  `carbs=30, fiber=40 ⇒ −10` bug the TDD guards).
- **No `now()` default on any clinical timestamp (ADR-8).** `datetime`,
  `pre_bg_time`, `post_bg_time`, `bolus_datetime`/`time_taken`, `bg_after_time`
  have **no** server/Python default — the app supplies the *reported* value
  (S-202). Only columns the doc marks "system clock — correct here"
  (`prediction_log.created_at`, `audit_log.changed_at`) use `server_default=
  func.now()`. `logged_at` is app-set (S-202), no DB default. The S-105
  `datetime.now()` guard covers the source either way.
- **`patient_profile` immutability** is enforced by a SQLAlchemy `before_update`
  guard that raises `ProfileImmutableError`. A change is a **new row**
  (new `profile_id`, new `effective_from`), never an UPDATE. This is REQ-054
  structural enforcement, not a core invariant (it defines no `inv<n>` function
  and no `SafetyViolation`; the S-104/S-105 hygiene guards stay green).
- **Coverage:** `data/` is **not** in the 90 % coverage set (09 §2 lists
  `core/features/models/prescribe`). It is tested thoroughly by round-trips but
  the gate does not apply; `[tool.coverage.run] source` stays `core` (DL-003).

## Public API (what the tests bind to)

## TDD strategy (SDET, written first — seen to fail)
`tests/integration/test_schema.py`:
1. **All tables created** — `Base.metadata` and a created DB both contain the 9
   table names.
2. **Signed offset** — `bolus_offset_min = −15` round-trips as `−15`.
3. **Computed floored net carbs** — `carbs=30, fiber=40 ⇒ net_carbs_g == 0`
   (not −10); `carbs=50, fiber=10 ⇒ 40`.
4. **Timestamps distinct** — a meal logged at 09:40 for an 08:00 mealtime stores
   `datetime=08:00`, `logged_at=09:40`; **assert they differ** and are separate
   columns.
5. **Profile versioned** — inserting a changed profile yields a **new row**
   (2 rows, distinct `profile_id`).
6. **Profile immutable** — mutating a persisted `patient_profile` and flushing
   raises `ProfileImmutableError`.
7. **Migration applies** — `alembic upgrade head` on an empty temp DB creates
   the full schema.
8. **ADR-8 guard** — no clinical-timestamp column carries a `now()`/Python
   default (asserted against the mapper), reinforcing the S-105 source guard.

**RED evidence:** `data.tables` / `data.db` do not exist ⇒ import error ⇒ fail.

**Adversarial angle:** the computed-floored net-carb column and the profile
immutability guard both exist to make a *silent* data corruption *structural and
impossible*, not merely discouraged.
