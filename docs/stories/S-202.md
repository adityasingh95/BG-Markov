# S-202 [SAFETY] — ★ Reported timestamps (ADR-8)

**Epic:** 2 (Data Layer) · **Safety story:** Yes · **Status:** Done

> *"The cheapest high-value story in the pack. Impossible to retrofit."* — backlog

## Story
Enforce, on the **write path**, the single rule that governs the whole data
model (`04` preamble, ADR-8): a clinical `datetime` is what she **reported**;
`logged_at` is the **system clock**; they are never the same field and one is
never used for the other. From those reported times — and only those — the two
most predictive features are derived: `bolus_offset_min` (signed) and
`elapsed_min`.

She logs at the laptop, often 30–40 min after eating. If any clinical time is
defaulted to `now()`, `bolus_offset_min` and `elapsed_min` become fiction, the
model trains on times that never happened, and **there is no error, no warning,
and no way to detect it afterwards.**

## Requirement sources
- **REQ-004** — every clinical timestamp is reported by the user, never
  defaulted to `now()`.
- **REQ-005** — `logged_at` (system clock) stored separately from `datetime`.

## Design
- **`Clock` abstraction (`core/clock.py`).** `SystemClock.now()` is the **one
  sanctioned** reader of the wall clock; it is used **only** for `logged_at`. The
  write-path functions take an injectable `Clock` so `logged_at` is deterministic
  in tests and so there is a single, greppable place the system clock is read.
- **Pure derivations (`core/timestamps.py`).**
  - `bolus_offset_min(meal_dt, bolus_dt) = round((bolus_dt − meal_dt) / 1 min)` —
    **signed**; negative = pre-bolus (bolus *before* the meal).
  - `elapsed_min(meal_dt, post_bg_dt) = round((post_bg_dt − meal_dt) / 1 min)`.
  Both take **reported** datetimes; neither ever reads a clock.
- **Write path (`data/recording.py`).** `record_meal(...)` sets
  `datetime = reported`, `logged_at = clock.now()`, and the derived fields from
  reported times. `record_post_bg(...)` sets `post_bg`, `post_bg_time` (reported)
  and `elapsed_min` from the reported reading time — never from when it was
  entered.

## Why this is safe — and how the guard already protects it [SAFETY]
The S-105 forbidden-pattern guard `detect_datetime_now_on_clinical_ts` matches
**any `.now()`/`.utcnow()`/`.today()` call** bound to a clinical-timestamp target
(`datetime`, `pre_bg_time`, `post_bg_time`, bolus time), and it **scans `data/`**.
Therefore:
- `logged_at = clock.now()` is allowed (`logged_at` is not a clinical-ts name).
- `meal.datetime = clock.now()` — or `= datetime.now()` — would **fail the S-105
  suite** the moment it is written, in `data/recording.py` like anywhere else.

So S-202 is the **first feature the S-105 guard actively guards**. This story
adds, on top of that, a *targeted* write-path guard: an AST test asserting that
inside `data/recording.py` a `now()` result is bound to **`logged_at` and nothing
else** — the positive statement of ADR-8 for the write path.

## TDD strategy (SDET, written first — seen to fail)
`tests/unit/test_timestamps.py` (pure, covered by the core gate):
- `bolus_offset_min`: 07:45 bolus, 08:00 meal ⇒ **−15**; 08:10 ⇒ **+10**; equal ⇒ 0.
- `elapsed_min`: 08:00 → 10:00 ⇒ **120**; 10:00 → 11:45 ⇒ **105**; rounding to the
  nearest minute.
- Property: a bolus before the meal is always negative; after, positive.

`tests/safety/test_reported_timestamps.py` (write-path discipline):
- **Log at 09:40 reporting an 08:00 mealtime** (fixed clock at 09:40) ⇒
  `datetime == 08:00`, `logged_at == 09:40`, **assert they differ**;
  `bolus_offset_min == −15` from reported times.
- **Post-BG entered at 11:30 for a 10:00 reading** ⇒ `elapsed_min` from **10:00**
  (== 120 for an 08:00 meal), never from 11:30.
- **AST guard:** in `data/recording.py`, every `now()` value is bound to
  `logged_at` only.

**RED evidence:** `core.clock` / `core.timestamps` / `data.recording` absent ⇒
import error ⇒ fail.

**Adversarial angle:** defaulting a clinical time to `now()` is the exact mistake
a coding agent makes on autopilot. The behavioural tests + the S-105 guard + the
targeted write-path guard make that mistake **loud**, at the first line that
commits it.
