# S-501 — ★ Baseline model (+ the shared state binner)

**Epic:** 5 (Baseline & Parameters) · **Safety story:** No, but touches INV-6 ·
**Status:** In progress · **Requirements:** REQ-030

> **Build this before a line of ML.** The baseline is the bar the model must beat;
> if the ordinal model cannot beat carbs + insulin arithmetic, that is a real and
> useful finding, not a failure. It is also the fallback when the kill switch
> trips, the guardrail-4 conflict check, and the ICR/ISF estimator. It takes an
> afternoon — and everything downstream is measured against it.

## Story
A pure baseline predictor of post-meal BG from carbs, insulin and IOB, and the
**shared state-binning function** that maps a BG to one of the 5 clinical states.
The binner lives here because the baseline, the ordinal model, and the risk readout
all bin the same way — one function, one boundary set.

## Requirement source
- **REQ-030 / 07 §4** — `predicted_post_bg = pre_bg + (carbs_g/ICR)·ISF −
  meal_bolus_units·ISF − correction_bolus_units·ISF − iob_at_meal·ISF`; bin into the
  5 states; score with the full metric suite.
- **03 §** — state boundaries `[54, 80, 181, 251]`: State 1 `<54`, 2 `54–79`,
  3 `80–180`, 4 `181–250`, 5 `>250`. **Ordering is load-bearing** (predicting 4
  when truth is 1 is catastrophic; 4-for-5 is minor).

## Design
- **`models/`** (new package — this is where the state-binner and models live,
  06 §arch). **Creating it arms the H3 binner tripwire**: this story registers the
  real binner name in the forbidden suite's `_BINNER_NAMES` so a renamed binner can
  never slip past the `pre_bg`→binner input guard.
- **`models/state.py`**:
  - `STATE_BOUNDARIES = (54, 80, 181, 251)`.
  - `bg_to_state(bg) -> int` — the shared binner, returns 1–5. **Binned on the
    OUTPUT only.** `pre_bg` is never passed here (the input guard enforces that).
- **`models/baseline.py`**:
  - `predict_baseline_bg(*, pre_bg, carbs_g, meal_bolus_units,
    correction_bolus_units, iob_at_meal, icr, isf) -> float` — the §4 formula.
    The prediction is a **predicted BG**, so **INV-6** is enforced on it: a value
    outside `[20, 600]` raises `SafetyViolation` (the invariant wired into the first
    place a prediction exists).
  - `predict_baseline_state(...) -> int` — `bg_to_state(predict_baseline_bg(...))`.
- Pure functions; `icr`/`isf` are passed in (from `patient_profile`); no clock,
  no DB.

## INV-6 note [SAFETY-adjacent]
The baseline is the first code that produces a *predicted BG*. INV-6 ("predicted BG
outside [20, 600] is a hard error") is enforced here on the raw continuous
prediction, before binning — an absurd prediction raises rather than silently
becoming State 5. Positive and negative tests included.

## TDD strategy (SDET, written first — seen to fail)
`tests/unit/test_state.py`:
- `bg_to_state` at every boundary: 53→1, 54→2, 79→2, 80→3, 180→3, 181→4, 250→4,
  251→5. Ordering holds (monotone non-decreasing in bg).

`tests/unit/test_baseline.py`:
- **Zero everything ⇒ post = pre:** carbs=bolus=corr=iob=0 ⇒ prediction == pre_bg.
- **★ Directionality:** doubling `carbs_g` **raises** the prediction; doubling
  `meal_bolus_units` **lowers** it; more `iob_at_meal` lowers it.
- **Golden — 5 hand-computed cases** (predicted BG to 2 dp for fixed ICR/ISF),
  plus the state each bins to.
- **INV-6:** an input set that predicts `> 600` (or `< 20`) raises
  `SafetyViolation`; an in-range case does not.

`tests/forbidden/test_forbidden_patterns.py` (already present): the binner tripwire
`test_pre_bg_binner_guard_is_armed_once_model_code_exists` now **runs** (no longer
skips) and passes because `bg_to_state` is registered in `_BINNER_NAMES`; the
`pre_bg`→binner scan stays clean (the baseline bins the prediction, not `pre_bg`).

**RED evidence:** `models/` does not exist ⇒ import errors; and the moment `models/`
lands, the binner tripwire fails until `bg_to_state` is registered.

**Adversarial angle:** the trap is binning on `pre_bg` (input) — which the forbidden
guard catches — or a non-monotone binner that misorders the states, turning a
catastrophic 1-for-4 error into a silent mislabel. The boundary and directionality
tests pin both.
