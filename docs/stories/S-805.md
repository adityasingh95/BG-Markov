# S-805 — Shadow-mode dashboard

**Epic:** 8 (Guardrails & Output) · **Safety story:** No (operator-only review) ·
**Status:** In progress · **Requirements:** REQ-048 (shadow mode ≥ 90 days), consumes
REQ-035 (metric suite)

> **Gate 1 is not opened by a row count; it is opened by the operator looking at the
> evidence and deciding the model has earned it.** This is the surface that evidence
> lives on: how well-calibrated the probabilities are, whether the model actually catches
> the lows, where its errors fall on the clinical danger grid, how its predictions line up
> against what really happened — and the one data-quality alarm that most threatens a
> single-patient model: an insulin coefficient that wanted to go negative.

## Story
Assemble an **operator-facing** shadow-mode report (pre-Gate-1; the operator is the sole
audience for model output before Gate 1) that aggregates the S-702 metric suite over the
logged predictions vs. their backfilled actuals: **calibration**, **hypo recall @ fixed
FAR**, the **Clarke error grid**, **predictions-vs-actuals**, off-by-one / severe-state
rates, and a **`β_insulin < 0` confounding warning**.

## Requirement source
- **REQ-048** — shadow mode ≥ 90 days before any patient-visible output; the operator
  reviews shadow output (01-prd: *"Sole audience for model output pre-Gate 1"*).
- **REQ-035 / 07 §9** — the metrics themselves (hypo recall @ FAR primary, Brier,
  calibration, Clarke, off-by-one). This story **composes** them for the operator; it does
  not redefine them.
- **07 §7 / INV-8** — `β_insulin < 0` (confounding by indication) is the signal about the
  data that must be surfaced, not swallowed. The dashboard raises it as a visible warning.

## Design
`models/shadow.py` (a reporting aggregator; imports `models.metrics` — no `core`):

- **`ShadowReport`** — `hypo_recall: HypoRecallResult`, `calibration: tuple[CalibrationBin,
  …]`, `brier: float`, `mae_mgdl: float`, `clarke: dict[str, int]`,
  `predictions_vs_actuals: dict[tuple[int, int], int]` (a sparse confusion matrix:
  `(predicted_state, actual_state) → count`), `off_by_one: float`, `severe_error: float`,
  `n_predictions: int`, and **`beta_insulin_confounding: bool`** +
  `unconstrained_beta_insulin: float` (the INV-8/S-503 alarm).
- **`build_shadow_report(*, hypo_score, is_hypo, predicted_bg, reference_bg, pred_states,
  actual_states, unconstrained_beta_insulin, states=(1,2,3,4,5), target_far=0.10,
  n_bins=10) -> ShadowReport`** — calls `hypo_recall_at_far`, `reliability_curve`,
  `clarke_grid`, `mae_mgdl`, `off_by_one_rate`, `severe_state_error_rate` (all S-702), and
  builds the confusion matrix. `beta_insulin_confounding = unconstrained_beta_insulin < 0`.

**Operator surface, not patient.** This report is for the operator's review during shadow
mode and never reaches the patient (INV-2 governs *patient* output; the operator is the
pre-Gate-1 audience by design). The HTML rendering lands with live wiring; the report
object is the testable core.

## TDD strategy (SDET, written first — seen to fail)
`tests/unit/test_shadow.py`:
- **Aggregates the suite.** On constructed inputs the report's `hypo_recall.recall`,
  `calibration` bins, `clarke` counts, `mae_mgdl`, `off_by_one`, and `severe_error` match
  the underlying S-702 metric outputs (the dashboard composes, does not recompute
  differently).
- **Predictions-vs-actuals.** The confusion matrix counts each `(predicted, actual)` pair
  correctly and sums to `n_predictions`.
- **★ `β_insulin < 0` warning.** `unconstrained_beta_insulin = −5.7` ⇒
  `beta_insulin_confounding is True`; a healthy `+30.0` ⇒ `False`. The most dangerous
  data-quality signal is surfaced, not hidden.
- **Clarke danger zones carried through.** A predicted-normal-truly-low pair lands in
  zone **D** in the report's grid (danger is preserved from S-702).

**RED evidence:** `models/shadow.py` does not exist ⇒ import error before impl.

**Adversarial angle:** the temptation is to headline the dashboard with a fat plain-
accuracy number so the model "looks ready" — the exact metric S-702 forbids. This report
composes only the honest metrics (recall @ FAR, calibration, Clarke danger) and puts the
`β_insulin < 0` alarm on the same screen, so a confounded or miscalibrated model cannot
look good to the operator deciding on Gate 1.
