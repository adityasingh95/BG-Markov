# S-103 [SAFETY] — Config loader

**Epic:** 1 (Foundation) · **Safety story:** Yes · **Status:** Done

## Story
Load the clinical constants (`07 §1`) into a **frozen, validated** in-process
config object. The config is the single typed source for `ISF`, `ICR`,
`target_bg`, the IOB curve constants, the basal halflife, and the operational
`max_bolus_u` cap. It refuses malformed input at load time — an `isf` that would
cause over-dosing, an out-of-range dose cap, or an unknown key that silently
does nothing — and it is immutable after load so nothing can mutate a clinical
constant mid-run.

This is **not** `patient_profile` (the versioned DB table, S-201). This is the
process configuration read at startup.

## The `icr`/`prescriptive_enabled` boundary — safety argument [SAFETY]

`prescriptive_enabled` is a **computed, read-only** property equal to
`icr is not None`. It is a *necessary precondition* for the prescriptive module,
**never a sufficient one and never a gate.** Specifically:

1. **It can only ever force OFF, never force ON.** `icr is None` ⇒ `False`,
   unconditionally. When `icr` is set, `prescriptive_enabled` is `True` — but
   `True` here means *"ICR is present"*, **not** *"Gate 2 is open."*
2. **It is not the invariant.** INV-1 ("prescriptive disabled until Gate 2
   passes") is enforced in `core/safety.py` (S-104) and evaluated from **live
   data on every call** (ADR-7 / `03 §3`: gates are *never cached, never
   configured, never stubbed*). The bolus calculator (S-901) calls the live gate
   check; it does **not** trust `config.prescriptive_enabled` as authorisation.
3. **It is therefore not a bypass.** `03 §3`: *"No bypass exists — not by
   fixture, not by mock, not by config flag, not by env var."* Because
   `prescriptive_enabled` is computed (not settable) and only ever *tightens*
   (ICR absent ⇒ off), no config value can open a gate that live data has not
   opened. The adversarial test asserts it cannot be forced `True`, and that
   setting it (like any field) raises on a frozen model.

`max_bolus_u`: the config validates its own field with a hard ceiling of **25 U**
(reject typos / misconfiguration). This is *distinct from* INV-3's **15 U**
recommendation cap, which is a constant in `core/safety.py` and the final
authority in the dose path. Config `max_bolus_u` can never *raise* the effective
recommendation cap above INV-3's 15 U; S-901 must clamp to
`min(config.max_bolus_u, MAX_BOLUS_U)`. Recorded for S-901 (decision log).

## TDD strategy (SDET, written first — seen to fail)
Floor from backlog: *property — `icr is None ⇒ prescriptive_enabled == False`;
config cannot raise `max_bolus_u` above the hard-coded ceiling.* Expanded to:

`tests/unit/test_config.py` (value validation):
1. Defaults match `07 §1` (isf 30, target_bg 135, iob_tp 55, iob_td 240,
   basal_halflife_h 25, max_bolus_u 15).
2. `isf = 0` and `isf = -1` raise; `isf = 0.1` loads.
3. `max_bolus_u = 26` raises; `= 25` loads; `= 0` raises; `< 0` raises.
4. Unknown key raises.
5. `iob_td <= iob_tp` raises (a degenerate IOB curve).
6. `load_config_file` round-trips a TOML file; a file with an unknown key raises.

`tests/safety/test_config_frozen.py` (adversarial):
7. **Property (hypothesis):** for any `icr ∈ {None} ∪ floats`,
   `prescriptive_enabled == (icr is not None)`.
8. Mutating **any** field on a loaded config raises (frozen).
9. `prescriptive_enabled` **cannot be assigned** (`config.prescriptive_enabled =
   True` raises) — it is not a settable bypass.
10. A config passed `prescriptive_enabled=True` **with `icr=None`** does not
    yield an enabled config — the unknown/derived key is rejected or ignored,
    never honoured as a bypass.
11. `max_bolus_u` above the ceiling raises regardless of any other field.

**RED evidence:** `core.config` does not exist ⇒ import error ⇒ all fail.

**Adversarial angle:** the frozen + can't-force-`True` tests exist so a future
refactor that makes the config mutable, or turns `prescriptive_enabled` into a
plain settable field "for convenience," turns the build red. That refactor is
exactly how a gate quietly becomes bypassable.
