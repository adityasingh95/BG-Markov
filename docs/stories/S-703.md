# S-703 [SAFETY] — ★ Gate enforcement

**Epic:** 7 (Validation) — **closes EPIC 7; unblocks EPIC 9** · **Safety story:** Yes,
the gatekeeper · **Status:** In progress · **Requirements:** REQ-040, REQ-041, **INV-1**,
**INV-2**

> **The gates are the reason this system is safe to build at all.** Gate 1 decides
> whether she ever *sees* a model output; Gate 2 decides whether the machine is ever
> allowed near a *dose*. Both must be **earned from live data on every call** — never a
> row count alone, never a cached "yes", never a flag someone can flip. `EPIC 9 (the
> prescriptive bolus module) stays hard-disabled until this is merged and green.`

## Story
Enforce the two gates as pure functions of **live** inputs, wired to the existing
invariants: **Gate 1** (INV-2 — patient-visible output) opens only when there are **≥ 150
valid meals AND the model's hypo recall beats the clinical baseline**; **Gate 2** (INV-1 —
the prescriptive/bolus module) opens only when a **confirmed ICR** exists (`icr` not
null). `recommend_bolus()` evaluates Gate 2 first, on every call, and there is **no
fixture, mock, config flag, or environment variable** that produces a recommendation with
`icr = null`.

## Requirement source
- **REQ-040 / INV-2** — no patient-visible model output before Gate 1.
- **REQ-041 / INV-1** — prescriptive module hard-disabled before Gate 2.
- **07 §… / ADR-7** — gates evaluated from **live data on every call; never cached.**
- **01-prd §… / 08 scenarios** — Gate 1 needs 150 valid meals **and** the model must
  *earn* visibility (SC-2: beat the baseline on hypo recall); *"Volume alone does not
  open Gate 1."* `icr` null ⇒ `GATE_NOT_PASSED`; *"No bypass exists."*

## Design
`prescribe/gates.py` (pure — imports only `core.safety`; gate **status** is application
logic, the raising invariants stay in `core/safety.py`):

- `GATE1_MIN_VALID_MEALS = 150` (consistency-tested against `data.adherence.GATE1_VALID_MEALS`).
- **`gate1_status(*, valid_meals, model_hypo_recall, baseline_hypo_recall) -> Gate1Status`**
  — `meets_volume = valid_meals ≥ 150`; `beats_baseline = model_hypo_recall >
  baseline_hypo_recall` (**strictly** — a tie does not open it); `is_open = meets_volume
  and beats_baseline`. Volume is **necessary, never sufficient**.
- **`gate2_status(*, icr) -> Gate2Status`** — `is_open = icr is not None and icr > 0`.
- **`require_gate1(status)`** → `inv2_patient_output_requires_gate1(status.is_open)` —
  raises `GateNotPassed` when closed.
- **`require_gate2(status)`** → `inv1_prescriptive_requires_gate2(status.is_open)` —
  raises `GateNotPassed` when closed.

`prescribe/bolus.py`:

- **`recommend_bolus(*, icr)`** — the prescriptive entry point. **First line** evaluates
  Gate 2 from the live `icr` and calls `require_gate2`; with `icr = null` it raises
  `GateNotPassed`. There is **no bypass parameter** (no `force`/`override`/`skip_gate`),
  and no env var or config flag is read. When Gate 2 *is* open, the dosing arithmetic is
  **EPIC 9** and not yet built, so it raises `NotImplementedError` — the gate opened, but
  the calculator does not exist until EPIC 9 lands on top of this merged story.

**Never cached (ADR-7).** The gate functions are pure functions of their live arguments —
no module-level flag, no `lru_cache`, no stored boolean. Each call recomputes from the
inputs handed in, which the caller reads fresh from the DB/metrics. A test proves the
result flips when the live input flips, within one process.

**CI wiring.** `prescribe` is added to the `mypy --strict` targets and the coverage gate
(`--cov=prescribe`, pyproject `source`), so the gatekeeper is type-checked and covered
like the rest of the safety surface.

## Written safety argument (why INV-1 & INV-2 cannot be bypassed) [SAFETY]
1. **The invariant is the only door.** `recommend_bolus` calls `require_gate2` →
   `inv1_prescriptive_requires_gate2` (`core/safety.py`, unchanged) as its first action;
   the function has no code path that reaches a dose without passing that call. With
   `icr = null`, `gate2_status().is_open` is `False`, the invariant raises, and the
   function cannot return.
2. **No bypass surface exists.** The signature accepts no override argument; the body
   reads no environment variable and no config flag. A test enumerates candidate bypass
   parameter names (absent from the signature) and sets bypass-looking env vars (ignored),
   proving there is no lever to pull. This is INV-1's "no fixture, mock, flag, or env var"
   made executable.
3. **Volume never buys visibility.** Gate 1 is a conjunction: `meets_volume AND
   beats_baseline`. 200 valid meals with hypo recall at or below the baseline leaves
   `is_open = False`, so `require_gate1` raises. The model must *earn* patient visibility
   by beating the baseline on the one metric that matters — row count alone is inert.
4. **Live, not cached (ADR-7).** The gate functions memoise nothing; a stale "open" from a
   prior good run cannot persist. Feeding `icr = null` after a valid call re-closes Gate 2
   on the very next call — proven by a test that flips the input mid-process.
5. **Fail-closed.** Every gate defaults to *closed*: the invariants raise unless explicitly
   passed `True`. A missing metric, a `None` ICR, or an unmet volume all resolve to
   "closed," never "open by omission."

## TDD strategy (SDET, written first — seen to fail)
`tests/safety/test_gates.py` (adversarial — assume a refactor will try to weaken these):
- **★ `icr = null` ⇒ `recommend_bolus()` raises `GateNotPassed`.**
- **★ No bypass:** no `force`/`override`/`skip_gate`/`bypass` parameter exists on
  `recommend_bolus`; setting bypass-looking env vars does **not** produce a recommendation;
  `GateNotPassed` still raises.
- **Gate 2 opens on a confirmed ICR:** with `icr` present, `recommend_bolus` gets **past**
  the gate (raises `NotImplementedError`, the EPIC-9 placeholder — *not* `GateNotPassed`).
- **Gate 1 volume floor:** 149 valid meals ⇒ `require_gate1` raises; 150 with
  `model_recall > baseline` ⇒ opens (no raise).
- **★ Volume alone never opens Gate 1:** 200 valid meals with `model_recall ≤ baseline` ⇒
  **still closed** ⇒ raises. A tie (`==`) does not open it.
- **Live, not cached:** `gate2_status(icr=None)` closed then `gate2_status(icr=8.3)` open
  in the same process; `recommend_bolus` flips behaviour when `icr` flips.
- **Invariant identity:** `GateNotPassed` is a `SafetyViolation`; the raise routes through
  `core/safety.py` (INV-1/INV-2), not a local re-implementation.
- **Constant consistency:** `GATE1_MIN_VALID_MEALS == data.adherence.GATE1_VALID_MEALS`.

**RED evidence:** `prescribe/gates.py` / `prescribe/bolus.py` do not exist ⇒ import error.

**Adversarial angle:** the tempting shortcut in EPIC 9 will be to stub `icr = 8.3` to get
the bolus tests running, or add a `force=True` for "testing." Both are hypo pathways for a
woman who cannot feel a low. These tests make the refusal path the *only* path when the
ICR is unconfirmed, and prove no lever exists to skip it — the gate **is** the feature.
