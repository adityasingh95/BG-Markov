# S-204 — Dish table

**Epic:** 2 (Data Layer) · **Safety story:** No · **Status:** In progress

## Story
Make a repeat meal a few taps instead of a 15-field form (the adherence
mechanism, `05b §3`). Ingest a dish table with macros **per household portion**;
scale by a portion multiplier (`2 × roti` = double `1 × roti`); and when she
types a dish that is not in the table, accept it as **free text** with a lowered
`macro_confidence` (60, not 95) and **queue it for the operator** to add
properly.

## Requirement source
- **REQ-009** — macros auto-populate from a dish table; free-text entry lowers
  `macro_confidence`.
- **`02 §F-1.1`** — portion via a multiplier stepper (not free-text grams);
  table dish ⇒ `macro_confidence = 95`; unknown ⇒ free text, `= 60`, queued.

## Acceptance criteria (backlog)
- [ ] IFCT 2017 ingest; macros stored **per household portion**.
- [ ] `2 × roti` = exactly double `1 × roti`.
- [ ] Free text ⇒ `macro_confidence = 60` (not 95), queued for review.

## Design
- **`core/macros.py`** (pure, core-covered): a `Macros` value type
  (carbs/protein/fat/fibre) with `scaled(servings)` — linear scaling. Confidence
  constants `TABLE_MACRO_CONFIDENCE = 95`, `FREE_TEXT_MACRO_CONFIDENCE = 60`.
- **`data/dishes.py`**:
  - `IFCT_SEED` — a small **representative** set of her repertoire (roti, dal,
    rice, rajma, sabzi, idli), macros per standard portion, `source=IFCT2017`.
    See the decision log: this is a seed pending the operator's real IFCT-2017
    values; the ingest path is what S-204 delivers, not the nutritional data.
  - `ingest_dishes(session, rows)` — bulk-load dish rows.
  - `find_dish(session, name)` — case-insensitive exact match.
  - `dish_macros(dish, servings)` — per-portion macros × servings.
  - `resolve_dish(session, name)` — table hit ⇒ `(dish, 95, needs_review=False)`;
    miss ⇒ create a queued free-text dish (`source=estimated`,
    `needs_review=True`, macros 0) and return `(dish, 60, needs_review=True)`.

## TDD strategy (SDET, written first — seen to fail)
`tests/unit/test_macros.py`:
- `Macros.scaled(2)` doubles every component; `scaled(0)` is zero; linearity.
- `TABLE_MACRO_CONFIDENCE == 95`, `FREE_TEXT_MACRO_CONFIDENCE == 60`.

`tests/integration/test_dishes.py`:
- Ingest `IFCT_SEED` ⇒ dishes present; `roti` has `source == IFCT2017`.
- `find_dish` is case-insensitive.
- **`dish_macros(roti, 2)` == exactly `2 × dish_macros(roti, 1)`** per component.
- `resolve_dish(known)` ⇒ confidence **95**, `needs_review == False`.
- `resolve_dish(free text)` ⇒ confidence **60** (not 95), `needs_review == True`,
  and a queued dish row exists (`needs_review`, `source == estimated`).

**RED evidence:** `core.macros` / `data.dishes` absent ⇒ import error.

**Adversarial angle:** free text defaulting to **95** would launder a guess as a
confident macro and silently over-weight it in training (`macro_confidence` is
the sample weight). The 60-not-95 test guards that.
